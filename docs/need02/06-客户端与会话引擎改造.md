# 06 客户端与会话引擎改造

## 1. 常量与注入点（双客户端同构）

`core/src/llm/openai.rs` + `core/src/llm/responses.rs` 各加：

```rust
/// 稳定会话头（服务端 KV 缓存路由用），开关关 → None
const SESSION_HEADER: &str = "x-opencode-session";

// struct 加字段
pub struct OpenAiClient {   // ResponsesClient 同
    http: reqwest::Client,
    base_url: String,
    api_key: Option<String>,
    model: String,
    session_header: Option<String>,  // ★ Some(会话ID) = 开
}
```

`new()` 取开关（此时尚无真实会话 ID，先占位，见 §2）：

```rust
pub fn new(cfg: &Resolved) -> anyhow::Result<Self> {
    let http = new_http_client()?;
    Ok(Self {
        http,
        base_url: cfg.base_url.trim_end_matches('/').to_string(),
        api_key: cfg.api_key.clone(),
        model: cfg.model.clone(),
        session_header: if cfg.session_header_enabled { Some(String::new()) } else { None },
        // 空串 = 开但值未到；Session 建好后经 set_session_header 回填
    })
}
```

`reconfigure()` 同步开关（关 → `None`，开但已有值 → 保留值，开且无值 → `Some("")` 占位）：

```rust
pub fn reconfigure(&mut self, cfg: &Resolved) {
    self.base_url = cfg.base_url.trim_end_matches('/').to_string();
    self.model = cfg.model.clone();
    self.api_key = cfg.api_key.clone();
    match (cfg.session_header_enabled, self.session_header.take()) {
        (false, _) => self.session_header = None,
        (true, Some(v)) if !v.is_empty() => self.session_header = Some(v),
        (true, _) => self.session_header = Some(String::new()),
    }
}

/// Session 建好/恢复后调用：值 = session_id；开但值为空时由调用方保证只在开时调
pub fn set_session_header(&mut self, enabled: bool, session_id: &str) {
    self.session_header = if enabled { Some(session_id.to_string()) } else { None };
}
```

统一加头 helper（推荐包在 `auth()` 里，一处覆盖全部发射点）：

```rust
fn auth(&self, req: reqwest::RequestBuilder) -> reqwest::RequestBuilder {
    let req = match &self.api_key {
        Some(k) => req.bearer_auth(k),
        None => req,
    };
    match &self.session_header {
        Some(v) if !v.is_empty() => match reqwest::header::HeaderValue::from_str(v) {
            Ok(hv) => req.header(SESSION_HEADER, hv),
            Err(_) => {
                eprintln!("⚠ 会话头值非法，已跳过（不影响本次请求）");
                req
            }
        },
        _ => req,
    }
}
```

- `auth()` 已被 `list_models/chat/chat_stream/validate(经 chat)` 全覆盖（01 §4），改一处即全生效。
- 若将来要绕过 `auth()` 的某条路径（如直连探针），必须显式调 `auth()`，禁止裸 `self.http.post()`。

`LlmClient` trait（`client.rs:11-36`）加默认方法（避免所有调用方大改）：

```rust
fn set_session_header(&mut self, _enabled: bool, _session_id: &str) {}
```

两客户端各自 `override` 为真实实现。

## 2. 建会话顺序（关键：先有 ID 再有头）

现状宿主多为"先 `build_llm_client(&resolved)` 再 `Session::new(llm, …)`"。`Session::new` 内生成 `id` 后（`session.rs:157-162`）立即回填：

```rust
// Session::new 尾部、push_system_prompt 之前或之后均可，须在任何 llm 调用前
if let Some(h) = ... // 无需读 resolved：llm 里的占位 Some("") 即"开"
{
    // 更直接：Session::new 加参 `session_header_enabled: bool`，或 new 后由宿主调
}
```

推荐形态（改动最小，不改 `Session::new` 签名）：宿主三处建会话点（交互首启 / `--resume` / 无头 `run_headless`）在 `Session::new` 返回后加一行：

```rust
session.set_session_header(resolved.session_header_enabled);
```

`Session` 新增：

```rust
/// 开关 + 当前 session_id 一起推给 client（新建/恢复/重配后调用）
pub fn set_session_header(&mut self, enabled: bool) {
    self.llm.set_session_header(enabled, &self.session_id.clone());
}
```

- 向导 `FetchModels` 探针 client（宿主临时 `OpenAiClient::new(&draft)`）：`draft.session_header_enabled` 为真但无会话 ID 时，用 `format!("wizard-{:x}", now_millis)` 探针值调 `set_session_header(true, &probe)`，仅用于验证连通性。

## 3. 恢复 / 重配 / 清空语义

| 事件 | 动作 |
|---|---|
| `load_history()`（`375-450`）切换 `session_id` 后 | 在发 `SessionInfo` 前加 `self.llm.set_session_header(ENABLED, &self.session_id)`；`ENABLED` 来源：`Session` 需新增字段 `session_header_enabled: bool`（`new` 时由宿主传入，`reconfigure` 时刷新），否则恢复后不知开关 |
| `Session::reconfigure(&resolved)`（`211-225`） | 先记 `self.session_header_enabled = resolved.session_header_enabled`；同协议走 `llm.reconfigure(resolved)`（保留旧值逻辑见 §1）后再 `set_session_header(enabled)` 刷新；跨协议重建 client 后同样刷一次 |
| `clear_context()`（`261-285`） | 不动（ID 不变，头的值不变） |
| `/config` 保存后 `Reconfigure(draft)` | 经上条自动生效，无需重启 |

因此 `Session` 需新增一个 `bool` 字段（`session_header_enabled`），`new()` 签名加参或 `Default(false)` + 宿主紧随 `set_session_header` 二选一；推荐加参（编译器强制所有建会话点补上，不遗漏无头路径）。
