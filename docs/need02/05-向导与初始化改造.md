# 05 向导与初始化改造（`tui/src/config_ui.rs` + `app.rs`）

## 1. 新步骤位置：Provider 之后、Querying 之前

需求原话"选择供应商之后" → 落点为 `Step::Provider` 回车后，不等 `Querying`：

```rust
pub enum Step {
    Provider,
    SessionHeader,   // ★ 新增
    Querying,
    ModelSelect,
    ProtocolSelect,
    ApiKey,
    ContextWindow,
    MaxTurns,
    Verifying,
}
```

- 为什么卡在 Querying 之前：`start_querying()`（`334-343`）发 `GET /models` 时即可按开关带探针头（02 §4），与正式语义一致。
- `custom` 供应商：手输端点提交后（`confirm_typed` 的 `Provider+custom` 分支，`639-647`）同样先落 `SessionHeader` 再 `start_querying`，不可跳过。

## 2. 交互形态（二选一，推荐 A）

- **A（推荐）：Y/n 确认步** —— 渲染两行选项 `是(Y, 默认) / 否(n)`，`↑↓/j/k` 移动 + `Enter` 确认；`Y/y` 直达是，`N/n` 直达否；`Esc` 回 `Provider`。
  - 默认值建议 `是`：需求动机即缓存优化，且头无副作用（服务端不识别则忽略）。
  - 若团队坚持最小打扰，则默认 `否`，验收标准 A1 的文案同步改。
- B：Provider 列表多一列复选框 —— 省一步但列表渲染与游标逻辑大改，不推荐。

新增字段：

```rust
pub session_header: bool,       // 待保存的开关（默认 false，apply 阶段按家带出）
pub session_cursor: usize,      // 0=是 1=否（或反之，与渲染一致）
```

## 3. 状态机改动清单

| 函数 | 改法 |
|---|---|
| `SetupWizard::new()`（`95-120`） | 初始化 `session_header=false, session_cursor=1(否)`；`providers` 列表不变 |
| `apply_provider_defaults()`（`125-164`） | 加 `self.session_header = def.map(\|d\| d.session_header).unwrap_or(false)` + 同步 `session_cursor`；换家即换开关，不沿用上一家 |
| `apply_config()`（`176-222`） | 同上，从 `all_providers()[&provider]` 带出；顶部"当前配置"摘要行（`728-744`）追加 `会话头 开/关` |
| `draft()`（`262-276`） | `Resolved{ …, session_header_enabled: self.session_header }` |
| `on_key()`（`357-575`） | `Step::Provider` 的 `Enter` 分支：置 `step=SessionHeader`（`custom` 先进 typing，提交后再进）；新增 `Step::SessionHeader` 分支处理上下/YN/回车/Esc；回车后才调原 `start_querying` |
| `render()`（`672-…`） | 步骤条数组（`684-692`）加一项（如 `"2 会话头"`，后续编号顺延）；`current` 映射加 `SessionHeader=>1`；新增该 step 的渲染段（问题文案 + 两选项 + 提示"同一会话内稳定，用于服务端缓存"） |
| `confirm_typed()`（`637-668`） | `custom` 端点提交分支改落点为 `SessionHeader` |

## 4. 宿主保存链路（`tui/src/app.rs:1193-1223`）

- `Config::save()` 签名加参 `session_header: bool`，调用点：
  ```rust
  cfg.save(&draft.provider_name, Some(&draft.model), Some(&draft.base_url),
           key_arg, w.context_window, draft.protocol, w.session_header)
  ```
- `cfg.save` 内：`entry.session_header = session_header;`（bool 直接赋值，无需 `filter`）。
- `AgentCmd::Reconfigure(draft)` 已带 `session_header_enabled`（`Resolved` 新字段），会话侧见 06 §3。
- 协议切换提示（`1212-1219`）旁可追加开关变化提示（可选；首版不强制）。

## 5. 首启与 `/config` 一致性

- 首启（`app.rs:509-515`）与 `/config`（`1045-1047`）均走 `new()+prefill()`，新步骤对两者自动生效，无需分叉。
- `has_configured()`（`224-227`）是否计入开关：不计入（开关单独不构成"已配置"，避免空配置显示摘要行）。
