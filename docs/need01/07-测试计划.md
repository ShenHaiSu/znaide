## 7.3 集成测试（`mock_e2e.rs` 追加，复用 `spawn_mock`）

mock handler 按请求 path 分流：若 body 含 `input` 键走 Responses 桩，否则走 chat 桩（保证"同一 mock 同时服务两种协议"，也可直接断言 `input` 存在）。

| 用例 | mock 行为 | 断言 |
|---|---|---|
| `responses_sse_text` | SSE 发 §2.4 的 message 部分 + completed(usage) | `chat_stream` 回 content=="你好…"，usage 正确，收到 TextDelta |
| `responses_tool_loop` | 第 1 次请求回 function_call(SSE)，第 2 次（body 含 function_call_output）回纯文本 | `Session::run_turn` 走完工具循环，工具被真实执行，结果回填，第二轮 input 含 output 项（在 handler 里断言 body `input` 含 `function_call_output`，否则 panic 让测试红） |
| `responses_non_stream_headless` | 非流式 `output:[message]` | `Session::run_turn`（无 events → `chat` 路径）返回文本 |
| `responses_compact_uses_responses` | 记录请求 body | `compact_context` 发出的请求是 Responses 形（含 instructions），摘要成功压缩 |
| `chat_regression_untouched` | 现有用例 | 不新增，只保证全过 |

`Session` 构造：`Session::new(build_llm_client(&resolved)?, …)`，其中 `resolved.protocol = Response`，`base_url` 指 mock 地址。

## 7.4 配置/向导回归

| 用例 | 位置 | 断言 |
|---|---|---|
| `protocol_default_chat` | config.rs | 空配置 `resolve().protocol == Chat`；`ProtocolKind::default() == Chat` |
| `protocol_per_provider` | config.rs | provider A=Response、B 缺省 → resolve(A)=Response，resolve(B)=Chat；字段级合并（只写 base_url 的用户条目不丢内置 protocol） |
| `protocol_env_and_cli` | config.rs | `ZNAIDE_PROTOCOL=response` 生效；CLI `Some(Response)` 覆盖 env `chat` |
| `protocol_save_roundtrip` | config.rs | save(Response) → 读回 `Some(Response)`；save(Chat) → 条目 `None`（干净性）；顶层 `protocol` 被清空 |
| `legacy_config_no_protocol` | config.rs | `serde_json::from_str(r#"{"model":"m"}"#)` → resolve 得 Chat（老文件零迁移） |
| 向导 `protocol_step_flow` | config_ui.rs tests | ModelSelect Enter → ProtocolSelect；`j` 切 response；Enter → ApiKey；Esc 回 ModelSelect；`draft().protocol` 正确；`apply_config` 预填落在已存值 |
| `parse_invalid_protocol` | config.rs | `"foo"` → None；`"Responses"`（复数/大小写）→ Response |

## 7.5 手工验证清单（真端点）

1. 向导走一遍：选 provider → 查模型 → 选模型 → **选 response** → key → 窗口/轮数 → 验证通过 → `config.json` 条目有 `"protocol":"response"`。
2. 对话：纯文本 2 轮（上下文连续正确，证明全量 input 重发有效）。
3. 工具连调：让模型列目录+读文件（至少一次多工具同轮）。
4. `/compact` 后继续对话；`/config` 切回 chat 继续对话；`--resume` 恢复。
5. `--protocol chat -p "hi"` 无头一次；`ZNAIDE_PROTOCOL=response` env 一次。
6. 断网/错 key 时的中文错误提示可读（`describe_request_error` 新增分支触发检查）。
